## Notes

- **Tableau Standard $15/user/міс** — точно як у документі.
- Включає: web authoring, Tableau Desktop, Prep Builder, Tableau Pulse.
- **Enterprise** $35/user/міс — для advanced management/security/scale.
- "Every deployment requires at least one Creator license" — тобто $15 — це нижня межа per-user; для повного deployment потрібен мінімум один Creator.
- Прямий доступ до tableau.com заблокований Akamai; верифікація через Wayback Machine архів — той самий контент, з кешу.
