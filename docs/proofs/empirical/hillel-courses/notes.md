## Notes

- **Hillel — multi-track школа**: програмування, QA, project/product management, BA, дизайн, маркетинг, англійська, дитячі курси. Це показує ширину ICP — наш продукт має покривати різні track-формати, не лише technical.
- **Refund-policy критична для retention-бізнесу**: 3 тижні на 100% повернення → **школа сама втрачає revenue, якщо учень дропне в цьому вікні**. Це сильно посилює бізнес-кейс — школа має **прямий фінансовий інтерес** утримати учня хоча б 3 тижні.
- **Канали оплати**: LiqPay + plata by mono — стандарт українського ринку, не Stripe. Для пост-хакатона: інтеграція з ними для signal "downgrade / failed payment" буде українсько-специфічна.
- **Конкретні ціни не в dump-і** (рендеряться з JS після кліку на конкретний курс). Скріншот містить картки курсів з цінами; з реальної експертизи команди (Nadin як ментор GoIT): український ринок IT-курсів — приблизно $500–$3000 за курс залежно від тривалості і типу. **Cycle через chat $400–2000 на учня — у межах цього діапазону.**
- **Висновок для нашого продукту**:
  - Hillel = доказ існуючої аудиторії з multi-track курсами і refund-чутливістю.
  - Перші 3 тижні (refund-вікно) = **наш ключовий момент моніторингу**: збігається з Jordan 2015 ([↗](#proof-jordan-2015-irrodl)) — "перші 1–2 тижні критичні для engagement".
